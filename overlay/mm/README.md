# MM overlay

Files placed below this directory are copied on top of `MoonModules/WLED-MM:mdev` before PlatformIO builds the Ultimate-MM channel.

Keep overlays small and reviewable. Do not mirror the complete upstream repository here.

Planned content:

- WLED Ultimate build/version branding
- selected default configuration changes
- stability fixes specific to WLED Ultimate
- board presets that are not suitable for upstream
